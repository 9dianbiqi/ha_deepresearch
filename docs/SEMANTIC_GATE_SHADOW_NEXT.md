# 下一阶段：Shadow Evaluation

当前Lite V1已冻结、离线验收；生产阻断关闭。此文是下一阶段范围记录，Shadow尚未实现或启用。

目标是在真实Planner输出上观察Lite V1是否提供增量价值，而不是开发Semantic Gate V2。

## 最小范围

- 默认关闭，明确开启后才旁路调用；继续使用冻结的三个语义检查。
- 输入是确定性门禁处理后的实际待执行计划副本，结果不修改、删除或替换任务，不触发Planner重规划。
- 主流程不等待Shadow结果；错误、超时和日志保存失败不改变研究终态，也不拖住规划执行。
- 单独限制调用并发与资源，不挤占正常研究；恢复运行不重复提交已观测的同一计划。
- 记录模型/提示词版本、计划指纹、判断与反馈、引用校验、耗时、用量和技术失败，遵循现有数据存储及访问边界。

## Badcase归类

真实请求没有天然正确答案。先记录疑似误拒、疑似漏判、无信息拒判、跨次判断不稳定和技术失败，之后再复核。模型fail不能自动记作真实缺陷，规则pass也不是语义完整的金标准。

合理语义歧义与模型未读出明确目标要分开；保留原计划、模型原始意见和复核依据，不用120B名称或引用合法性代替正确性证明。

## 本阶段验收

只验收旁路不影响规划、失败不影响正常执行、观测记录可追溯及调用资源受控。不得把部署Shadow写成生产阻断已验收。

既有12例开发测试和已完成回归不重复运行；仅对新增Shadow行为做必要检查。真实分布积累足够独立证据、事先定义误拒/漏判标准后，才讨论是否开启阻断。
